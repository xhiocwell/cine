# Sistema de Gestipn de Cine - API REST

Este proyecto es una API REST desarrollada para administrar un cine. Permite gestionar las salas, el catalogo de peliculas con sus generos, la programacion de funciones, los clientes y la venta de boletos
La API esta construida siguiendo una arquitectura en N-capas (Controller → Service → Repository) 

##  Requisitos Previos

Antes de ejecutar el proyecto, asegurate de tener instalado:
*   [Node.js](versipn 18 o superior)
*   [MySQL](XAMPP con MySQL)

## Instalacipn y Configuracipn
   cd cine-api
   npm install
   npm run start:dev

   http://localhost:3000/docs#description/introduction
